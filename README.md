# デジタル教科書ランチャー

TT-sensei `learning-portal` 内の、デジタル教科書の公式ログイン先を「教科」から開くためのランチャーです。

## 基本の考え方

使う人には「教科」を入口として見せ、登録するときだけ「教科書会社」と「サイト名」を選びます。URLを通常利用者に入力させません。

- 子ども・大人：教科 → ひらく
- 登録：教科 → 教科書会社 → サイト名 → 保存
- 教科書会社を選ぶと、確認済みの対応サイトを自動選択
- 必要ならサイト名を変更可能
- 「教科書登録モード」として、特定の立場に限定しない

## 公式ログイン先

令和8年度の文部科学省「各社対応先一覧」を基準に、次の6サービスを登録候補として用意しています。

| サイト名 | 公式ユーザーログイン |
| --- | --- |
| Lentrance Reader | https://www.lentrance.com/school/login |
| つばさブック | https://tsubasabook.jp/ |
| まなビューア | https://manaviewer.jp/ |
| みらいスクールプラットフォーム | https://mirai-pf.jp/user/login.html |
| 超教科書 | https://p01.cloud.cho-textbook.jp/ |
| エスビューア | https://sviewer.jp/ |

対応関係は文部科学省の令和8年度案内を基準にしています。発行者によっては同じサイトを利用し、発行者によっては個別のログイン方式があります。未知の組み合わせを勝手に推測せず、「その他の公式ログイン先」から利用者が確認済みのURLを登録できる設計です。

## 対応出版社の初期候補

東京書籍→Lentrance Reader、大日本図書→つばさブック、光村図書出版→まなビューア、開隆堂出版→みらいスクールプラットフォーム、新興出版社啓林館→超教科書、数研出版→エスビューアを初期候補として登録しています。

三省堂、学校図書、教育出版、日本文教出版は、令和8年度の文部科学省一覧で使用ビューア欄が空欄になっているため、アプリ側で特定ビューアを推測していません。

## 役割と安全設計

このページはデジタル教科書本体を提供するものではなく、各社の公式ログイン先へ移動する入口です。

- ID・パスワードを入力・保存しない
- 教材本文・教材画像・デジタル教科書データをコピーしない
- 公式サイトをiframe等で埋め込まない
- 登録した公式ログイン先を新しいタブで開く

## 保存

保存namespaceは `digital-textbook-launcher`、キーは `state-v2` です。

通常は `edu-components` の `StorageManager` を使用します。共通基盤へ接続できない場合だけ、軽量なlocalStorageフォールバックを使用します。

保存されるのは教科書登録、表示順、お気に入り、最近の利用履歴です。アカウント情報は保存しません。

設定はJSONへ書き出し・読み込みできるため、別端末へ移すこともできます。

## PWA

`manifest.webmanifest` と `sw.js` を使用し、対応ブラウザではホーム画面へ追加してランチャーとして利用できます。外部のデジタル教科書サイト自体はキャッシュしません。

## edu-kitとの接続

- `edu-effects`：共通の教育向けUI基盤
- `edu-components`：`StorageManager` による端末内保存
- `edu-assets`：ホームアイコン等の軽量アセット
- `navi-character-`：案内役として控えめに表示

学習問題、報酬、効果音など、ランチャーの目的に不要な要素は使用しません。
